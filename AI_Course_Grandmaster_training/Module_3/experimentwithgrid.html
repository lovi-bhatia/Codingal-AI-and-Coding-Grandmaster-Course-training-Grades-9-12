Learning the Bootstrap 12 Column Grid System

1. Basic 12 Column System

Every row has 12 columns total. col-12 takes all 12 columns (full width)

col-12 (Full Width - takes all 12 columns)

8. Column Offset (Push Columns)

offset-[number] adds empty space BEFORE a column

<div class="col-4 offset-4"> (4 empty + 4 column + 4 empty) Column is pushed to center using offset
col-4 offset-4 (centered)
<div class="col-6 offset-3"> (3 empty + 6 column + 3 empty) Another way to center a column
col-6 offset-3 (centered)

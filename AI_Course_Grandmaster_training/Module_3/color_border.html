4. Subtle backgrounds (bg-*-subtle + text-*-emphasis)

Pre-blended soft colors. Always pair them with the matching text-*-emphasis class.

container-fluid bg-primary-subtle text-primary-emphasis Info notice — soft blue, easy on the eyes.
container-fluid bg-success-subtle text-success-emphasis Success notice — soft green.
container-fluid bg-danger-subtle text-danger-emphasis Danger notice — soft red.
container-fluid bg-warning-subtle text-warning-emphasis Warning notice — soft yellow.

9. Rounded corners — ⚠ needs margin to be visible

A full-bleed container-fluid clips its corners at the screen edge. Add mx-3 (or my-2) so you can actually see them.

container-fluid bg-primary ← no rounding, no margin Corners touch the screen edge — rounding would be invisible here
container-fluid mx-3 rounded rounded (≈0.375rem)
container-fluid mx-3 rounded-0 rounded-0 (square — the default)
container-fluid mx-3 rounded-3 rounded-3 (bigger radius)
container-fluid mx-3 rounded-pill rounded-pill (fully rounded ends)
container-fluid mx-3 rounded-top rounded-top (only the top corners)

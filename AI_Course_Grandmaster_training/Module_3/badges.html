Bootstrap 5 Badges

Topic: Inline indicators, contextual colors, pill shapes, and absolute positioning.

1. Code Examples

Contextual Background Colors

Badges use standard background utility classes .bg-{color}.

Solid Backgrounds: Primary Secondary Success Danger Warning Info Light Dark

Pill Badges

Use .rounded-pill for rounded oval borders.

Pill Variants (.rounded-pill): Primary Active 99+ Pending

Subtle Badges

Combine .bg-*-subtle with .text-*-emphasis for low-contrast labels.

Subtle Colors: Primary Completed Failed In Progress

3. Quick Reference

Pattern Required Classes
Standard Badge class="badge bg-primary"
Pill Badge class="badge rounded-pill bg-success"
Light Color Contrast class="badge bg-warning text-dark"
Subtle Badge class="badge bg-info-subtle text-info-emphasis"
Parent Container (for overlays) class="position-relative"
Overlay Badge Position class="position-absolute top-0 start-100 translate-middle"

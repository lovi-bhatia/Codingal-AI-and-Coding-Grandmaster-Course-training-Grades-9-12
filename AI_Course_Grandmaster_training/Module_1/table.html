How to Build Tables in HTML

Tables are created row by row. First you make a row, and then you fill that row with data cells.

Example 1: 9th Grade Class Schedule

We use <th> for the top row to create bold headers.

Period Subject Teacher Room
1st Algebra I Mr. Smith 104
2nd Biology Ms. Frizzle 201
3rd World History Mrs. Vance 108
4th Physical Education Coach Carter Gym

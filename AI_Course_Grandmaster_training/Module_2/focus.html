CSS Focus State

1. Default Browser Focus

Browsers add a default focus indicator automatically Click on the input below to see default outline

No CSS added - browser default focus outline Click on the input to see default browser focus

2. :focus - Border Colour Change

Most common focus effect Border colour changes when input is clicked outline: none removes the default browser outline

input:focus { border-color: #1e90ff; outline: none; } Click each input to see border colour change

3. :focus - Glow Shadow Effect

box-shadow creates a glow around the input Makes focused input very clear and visible Used in most modern websites and apps

input:focus { border-color: blue; box-shadow: 0px 0px 8px rgba(blue, 0.6); } Click each input to see glowing shadow

4. :focus - Background Colour Change

Background colour of input changes on focus Makes it very clear which field is active

input:focus { background-color: #e0f0ff; border-color: #1e90ff; } Click each input to see background colour change

5. :focus - Custom Outline Styles

Custom outline styles instead of default browser outline outline-offset adds space between element and outline

input:focus { outline: 3px solid blue; outline-offset: 2px; } Click each input to see different outline styles

6. :focus - Combined Effects

Multiple CSS properties changed at once on focus Creates more dramatic and impressive effects

input:focus { border-color + box-shadow + transform combined; } Click each input to see combined effects

7. :focus on Buttons

Buttons also need focus styles for keyboard users Press Tab key to navigate to buttons and see focus

Various button focus styles shown below Click buttons OR press Tab key to focus them

8. :focus on Textarea

Textarea gets the same focus styles as input Click inside the textarea to see focus effect

textarea:focus { border-color: #1e90ff; box-shadow: glow; background-color: #f0f8ff; } Click inside the textarea to see focus effect

9. :focus on Select Dropdown

Select dropdowns also support focus styles Click the dropdown to see focus effect

select:focus { border-color: #9932cc; box-shadow: purple glow; } Click the dropdown to see purple focus glow

10. :focus-within

Parent element changes style when any child inside it gets focused The whole group highlights on input focus

.form-group:focus-within { border-color: blue; background-color: #f0f8ff; } Click inside each input to see whole group highlight

11. :focus-visible

Shows focus ring ONLY for keyboard users Mouse users do not see the focus ring Press Tab key to focus the button and see ring

btn:focus { outline: none; } btn:focus-visible { outline: 3px solid blue; } Click button with mouse - no ring visible Press Tab key to reach button - ring appears

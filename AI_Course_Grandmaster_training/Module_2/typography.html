CSS Typography

1. font-family

Controls the STYLE of the font used for text

font-family: Arial, sans-serif;

This is Arial font - clean and simple

font-family: Times New Roman, serif;

This is Times New Roman - formal and classic

font-family: Courier New, monospace;

This is Courier New - looks like code

font-family: Georgia, serif;

This is Georgia - elegant and readable

font-family: Poppins (Google Font);

This is Poppins - modern and friendly

font-family: Playfair Display (Google Font);

This is Playfair Display - elegant and stylish

2. font-size

Controls how BIG or SMALL the text appears

font-size: 12px;

This text is 12px - very small

font-size: 16px;

This text is 16px - normal size

font-size: 24px;

This text is 24px - medium

font-size: 36px;

This text is 36px - large

font-size: 48px;

This is 48px

3. font-weight

Controls how THICK or THIN the text appears

font-weight: 100;

This is font-weight 100 - thinnest

font-weight: 300;

This is font-weight 300 - thin

font-weight: 400 (normal);

This is font-weight 400 - normal

font-weight: 600;

This is font-weight 600 - semi bold

font-weight: 700 (bold);

This is font-weight 700 - bold

font-weight: 900;

This is font-weight 900 - thickest

4. font-style

Controls if text is ITALIC or normal

font-style: normal;

This is normal font style - upright text

font-style: italic;

This is italic font style - slanted text

font-style: oblique;

This is oblique font style - also slanted

5. font-variant

Controls if text shows as SMALL CAPITALS

font-variant: normal;

hello world - this is normal text

font-variant: small-caps;

hello world - this is small caps text

6. text-align

Controls horizontal POSITION of text

text-align: left;

This text is aligned to the LEFT side of the box

text-align: center;

This text is aligned to the CENTER of the box

text-align: right;

This text is aligned to the RIGHT side of the box

text-align: justify;

This text is justified which means it is spread out to fill the full width of the box just like you see in newspapers and books every line is the same width

7. text-decoration

Adds LINES to the text

text-decoration: underline;

This text has an underline below it

text-decoration: overline;

This text has an overline above it

text-decoration: line-through;

This text has a line through the middle

text-decoration: none;

This text has no decoration at all

8. text-transform

Changes the CASE of the text

text-transform: uppercase;

this text becomes all capitals

text-transform: lowercase;

THIS TEXT BECOMES ALL SMALL LETTERS

text-transform: capitalize;

first letter of every word becomes capital

text-transform: none;

tHiS tExT stays exactly as typed

9. text-indent

Adds space at the START of first line like pressing Tab key

text-indent: 50px;

This paragraph has text-indent of 50px. Only the first line is pushed in. The rest of the lines stay at normal position. This is just like indenting in a book or essay.

10. text-shadow

Adds a SHADOW behind the text syntax: horizontal vertical blur colour

text-shadow: 2px 2px 4px gray;

Simple Gray Shadow

text-shadow: 3px 3px 0px #003366;

Coloured Shadow Effect

text-shadow: 0px 0px 10px and 20px orange glow;

Glowing Text Effect

text-shadow: 2px 2px red, -2px -2px blue;

Multiple Shadows

11. line-height

Controls SPACE between lines of text

line-height: 1;

This has line-height 1. Lines are very close together. It is hard to read when too tight.

line-height: 1.5;

This has line-height 1.5. This is the recommended value. It is comfortable to read.

line-height: 2;

This has line-height 2. There is double space between lines. Good for headings or quotes.

line-height: 3;

This has line-height 3. Lines are very far apart. Too much space between lines.

12. letter-spacing

Controls SPACE between individual letters

letter-spacing: normal;

This is normal letter spacing

letter-spacing: 5px;

This has wide letter spacing

letter-spacing: 10px;

This has wider spacing

letter-spacing: -1px;

This has tight letter spacing

13. word-spacing

Controls SPACE between words

word-spacing: normal;

This has normal word spacing between words

word-spacing: 10px;

This has wide word spacing between words

word-spacing: 20px;

This has wider word spacing between words

14. font Shorthand Property

Combines all font properties in ONE line syntax: style variant weight size/line-height family

font: italic small-caps bold 24px/2 Georgia, serif;

This uses font shorthand with all properties combined

CSS Basic Transform

1. Translate - Move the Element

translateX moves LEFT or RIGHT translateY moves UP or DOWN Positive values move right or down Negative values move left or up

Original
No Transform
Moved Right
translateX(80px)
Moved Down
translateY(60px)
Moved Both
translate(50px, 40px)
Moved Left
translateX(-60px)

2. Rotate - Spin the Element

Positive degrees rotate CLOCKWISE Negative degrees rotate ANTI-CLOCKWISE Full circle = 360deg

Original
No Transform
45deg
rotate(45deg)
90deg
rotate(90deg)
180deg
rotate(180deg)
-45deg
rotate(-45deg)
Flip X
rotateX(60deg)
Flip Y
rotateY(60deg)

3. Scale - Resize the Element

Value above 1 makes BIGGER Value below 1 makes SMALLER Value of 1 is original size

Original
No Transform
Bigger
scale(1.5)
Smaller
scale(0.5)
Wide
scaleX(2)
Tall
scaleY(2)

4. Skew - Tilt the Element

skewX tilts HORIZONTALLY skewY tilts VERTICALLY Makes element look like a parallelogram

Original
No Transform
Skew X
skewX(20deg)
Skew Y
skewY(15deg)
Skew Both
skew(20deg, 10deg)
Skew -X
skewX(-20deg)

5. Multiple Transforms Combined

Write transforms one after another with a space Each transform is applied in order left to right

Original
No Transform
Move + Rotate
translateX(50px) rotate(45deg)
Scale + Rotate
scale(1.3) rotate(30deg)
All Three
translateY(-30px) scale(1.2) rotate(15deg)

6. Transform Origin

Changes the CENTER POINT of the transformation Default is center center which is middle of element

Center
transform-origin: center center
Top Left
transform-origin: top left
Bottom Right
transform-origin: bottom right

7. Transform with Transition - Hover Effects

Hover over the boxes to see SMOOTH transform changes transition property makes the change gradual

Hover to Scale
scale(1.3) on hover
Hover to Rotate
rotate(180deg) on hover
Hover to Slide
translateY(-40px) on hover
Hover to Skew
skewX(20deg) on hover
Hover for All
scale rotate translate on hover

CSS Box Model

1. Box Model Diagram

Every HTML element is made of 4 layers From outside to inside: Margin Border Padding Content

Visual diagram of all 4 layers of the Box Model
MARGIN (yellow) - space outside

BORDER (dark) - line around padding

PADDING (green) - space inside

CONTENT (blue)
Text and Images live here

2. Content - width and height

Content is the innermost layer where text lives width and height control the size of content area

width: 250px; height: 100px; Fixed size in pixels - always same size
width: 250px
height: 100px
Fixed pixel size
width: 60%; height: 80px; Width is 60% of parent - changes with screen size
width: 60% of parent container
min-width: 150px; max-width: 400px; width: 50%; Width is 50% but never smaller than 150px or bigger than 400px
min-width: 150px max-width: 400px

3. Padding - Space Inside

Padding is space INSIDE the element between content and border Padding has same background colour as the element

padding: 0; (no padding)
No Padding - content touches border
padding: 20px; (all four sides same)
padding: 20px all sides
padding: 5px 30px; (top/bottom=5px left/right=30px)
padding: 5px 30px
padding: 5px 20px 30px 40px; (top right bottom left)
padding: 5px 20px 30px 40px
padding-top: 30px;
padding-top: 30px only
padding-left: 40px;
padding-left: 40px only

4. Border - Line Around Element

Border sits between padding and margin Needs three values: width style colour

Different border-style values
border: 3px solid blue
border: 3px dashed red
border: 3px dotted green
border: 6px double purple
border: 5px groove orange
border: 5px ridge teal
border: 5px inset navy
border: 5px outset crimson
Different border on each side top solid red right dashed blue bottom dotted green left double purple
border-radius values for rounded corners
border-radius: 5px slight round
border-radius: 15px medium round
border-radius: 30px very round
border-radius: 50% full circle
top-left and bottom-right rounded only

5. Margin - Space Outside

Margin is space OUTSIDE the element between elements Margin is always transparent no background colour

margin: 0; (no margin - boxes touch)
Box A - no margin
Box B - no margin
margin: 20px; (space on all sides)
Box with margin: 20px
Box with margin: 20px
margin-top: 20px; margin-bottom: 20px;
margin top and bottom 20px
margin top and bottom 20px
margin-left: 60px; (pushes box to the right)
margin-left: 60px
margin: 10px auto; (centers element horizontally) width must be set for auto margin to work
margin: auto - I am centered!

6. box-sizing Property

Controls how width and height are calculated content-box = default, border-box = recommended

Both boxes have width: 200px padding: 20px border: 5px content-box total visible width = 200+20+20+5+5 = 250px border-box total visible width = 200px (padding inside)
box-sizing: content-box
width: 200px
Actual visible: 250px
Padding ADDED to width
box-sizing: border-box
width: 200px
Actual visible: 200px
Padding INSIDE width

7. Padding vs Margin Comparison

Padding = space INSIDE (background colour shows) Margin = space OUTSIDE (always transparent)

margin: 30px

display controls how the box model behaves block inline and inline-block all work differently

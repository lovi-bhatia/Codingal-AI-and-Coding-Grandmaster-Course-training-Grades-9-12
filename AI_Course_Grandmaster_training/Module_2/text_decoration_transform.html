Text Decoration and Text Transform

1. text-decoration-line

Controls WHERE the line appears on the text

text-decoration-line: none;

This text has NO decoration line at all

text-decoration-line: underline;

This text has a line BELOW it

text-decoration-line: overline;

This text has a line ABOVE it

text-decoration-line: line-through;

This text has a line THROUGH the middle

text-decoration-line: underline overline;

This text has lines ABOVE and BELOW

2. text-decoration-color

Changes the COLOUR of the decoration line Line colour can be different from text colour

text-decoration-color: red;

This text has a RED underline

text-decoration-color: blue;

This text has a BLUE underline

text-decoration-color: orange;

This text has an ORANGE line through it

text-decoration-color: green;

This text has a GREEN overline

3. text-decoration-style

Changes the PATTERN or STYLE of the line

text-decoration-style: solid;

This line is SOLID - plain straight line

text-decoration-style: double;

This line is DOUBLE - two parallel lines

text-decoration-style: dotted;

This line is DOTTED - made of dots

text-decoration-style: dashed;

This line is DASHED - made of dashes

text-decoration-style: wavy;

This line is WAVY - squiggly like spelling error

4. text-decoration-thickness

Controls how THICK or THIN the line is

text-decoration-thickness: 1px;

This line is very THIN at 1px

text-decoration-thickness: 3px;

This line is MEDIUM at 3px

text-decoration-thickness: 6px;

This line is THICK at 6px

text-decoration-thickness: 10px;

This line is VERY THICK at 10px

5. text-decoration Shorthand

Write all decoration properties in ONE line syntax: line colour style thickness

text-decoration: underline red wavy 2px;

Red wavy underline using shorthand

text-decoration: line-through blue solid 3px;

Blue solid strikethrough using shorthand

text-decoration: overline green dotted 2px;

Green dotted overline using shorthand

text-decoration: underline orange dashed 4px;

Orange dashed underline using shorthand

6. Practical Uses of Text Decoration

Real examples where text decoration is used

Remove underline from link: text-decoration: none;

Click here to visit website (link without underline)

Old price strikethrough: text-decoration: line-through red;

Original Price: Rs 999

Spelling error: text-decoration: underline red wavy;

This word is spelt wrongly

Important text: text-decoration: underline double;

This is very important information

7. text-transform

Changes the CASE of text on screen The actual HTML text does not change Only the display on screen changes

text-transform: none;

hElLo WoRlD - text stays exactly as typed

text-transform: uppercase;

hello world becomes all capital letters

text-transform: lowercase;

HELLO WORLD BECOMES ALL SMALL LETTERS

text-transform: capitalize;

first letter of every word becomes capital

8. Practical Uses of Text Transform

Real examples where text transform is used

Button text uppercase: text-transform: uppercase;
buy now
add to cart
sign up
Name or title capitalize: text-transform: capitalize;

my name is doraemon nobita shizuka

Username lowercase: text-transform: lowercase;

Username: DORAEMON_123 displays as doraemon_123

9. Combining Text Decoration and Text Transform

Both properties can be used on the SAME element at the same time

text-transform: uppercase + text-decoration: underline red wavy;

hello this text is uppercase with wavy red underline

text-transform: capitalize + text-decoration: underline blue double;

my favourite cartoon is doraemon

text-transform: lowercase + text-decoration: line-through orange;

THIS ITEM IS NO LONGER AVAILABLE

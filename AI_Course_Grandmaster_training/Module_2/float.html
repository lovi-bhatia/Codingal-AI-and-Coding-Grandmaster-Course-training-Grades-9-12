2. float: left

Element moves to the LEFT side of container Other content wraps around it on the RIGHT

float: left; margin-right: 15px; Blue box floats left - text wraps on right side
float: left

This text wraps around the floated blue box on the left. The float: left property moves the blue box to the left side and this text fills in around it on the right side. This is similar to how text wraps around images in newspapers and magazines. The text continues to flow naturally until it passes the bottom of the floated element.

3. float: right

Element moves to the RIGHT side of container Other content wraps around it on the LEFT

float: right; margin-left: 15px; Red box floats right - text wraps on left side
float: right

This text wraps around the floated red box on the right. The float: right property moves the red box to the right side and this text fills in around it on the left side. This is the opposite of float left. The text continues to flow naturally on the left side until it passes the bottom of the floated red element.

The most correct and original use of float Makes text wrap around images like a magazine

8. Two Column Layout Using Float

Classic layout using float Main content on left sidebar on right

.col-main { float: left; width: 65%; } .col-sidebar { float: right; width: 33%; } .footer { clear: both; }

Main Content Area

This is the main content area floating to the left. It takes up 65% of the container width. This is where the main article or page content goes. Float was used here to create a two column layout. The sidebar appears to the right of this content.

Sidebar

This sidebar floats to the right. It takes 33% of width. Used for extra info links or ads.

Footer - clear: both - appears below both columns

CSS Hover State

1. :hover on Buttons

Move your mouse OVER the buttons to see the effect Move mouse AWAY to see it go back to normal

btn:hover { background-color: #003366; } Hover to change background colour
btn:hover { color: #003366; border-color: #003366; } Hover to change text and border colour
btn:hover { transform: scale(1.1); } Hover to see button grow bigger
btn:hover { transform: translateY(-5px); box-shadow: bigger; } Hover to see button lift up with shadow
btn:hover { box-shadow: 0px 0px 15px 5px purple; } Hover to see glowing shadow appear
btn:hover { background-color: #ff8c00; color: white; } Hover to see button fill with colour
btn:hover { transform: rotate(5deg) scale(1.05); } Hover to see button rotate slightly
btn:hover { letter-spacing: 5px; } Hover to see letters spread apart

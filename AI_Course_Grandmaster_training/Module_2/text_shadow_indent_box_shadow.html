2. text-indent

Adds empty space at the START of the first line only Like pressing Tab before writing a paragraph

text-indent: 0px; (no indent - default)

This paragraph has no indent. The first line starts at the same position as all other lines. All lines are aligned to the left edge of the box.

text-indent: 30px;

This paragraph has 30px indent. Only the first line is pushed 30px to the right. The second line goes back to the normal left position as you can see.

text-indent: 60px;

This paragraph has 60px indent. The first line is pushed quite far to the right. Remaining lines are at the normal left position without any indent.

text-indent: 100px;

This paragraph has 100px indent. The first line starts very far to the right. Only the first line is affected all other lines are at normal position.

text-indent: 3em; (3 times the font size)

This paragraph uses em unit for indent. 3em means 3 times the font size. If font is 18px then indent is 54px. Em is relative to the font size used.

text-indent: 5%; (5 percent of container width)

This paragraph uses percentage for indent. 5% means 5 percent of the width of this container box. This is useful for responsive designs on any screen size.

text-indent: -30px; (hanging indent - first line sticks out)

This paragraph has a negative indent called hanging indent. The first line sticks out to the left side while all other lines are at the normal position. This style is used in bibliography and reference lists.

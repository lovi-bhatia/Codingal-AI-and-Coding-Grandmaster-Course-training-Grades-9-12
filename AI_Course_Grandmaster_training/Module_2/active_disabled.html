Active and Disabled States

1. :active on Buttons

Style applies ONLY while the button is being clicked Click and hold the buttons to see the effect

btn:active { background-color: darkblue; } Click and hold to see colour change
btn:active { transform: scale(0.92); } Click and hold to see button shrink
btn:active { transform: translateY(4px); box-shadow: smaller; } Click and hold to see button push down
btn:active { box-shadow: inset 3px 3px 8px rgba(0,0,0,0.4); } Click and hold to see inset shadow appear
btn:active { background-color: #003366; color: white; } Click and hold to see button fill with colour
btn:active { transform: scale(0.95) translateY(3px); box-shadow: smaller; } Click and hold to see combined effects

2. :active on Links

Links also support :active state Click and hold the links to see the effect

a:active { color: red; } Click and hold to see colour change to red

a:active { background-color: #003366; color: white; } Click and hold to see background change

4. Disabled Buttons

Add disabled in HTML tag to turn off the button Style with :disabled in CSS Disabled buttons CANNOT be clicked at all

Enabled button vs Disabled button comparison Left button works - Right button is disabled
btn:disabled { background-color: #ccc; color: #888; cursor: not-allowed; }
btn:disabled { opacity: 0.4; cursor: not-allowed; }
btn:disabled { color: #aaa; border-color: #ccc; cursor: not-allowed; }
btn:disabled { text-decoration: line-through; color: #aaa; }

5. Disabled Input Fields

Input fields can also be disabled Disabled inputs cannot be typed into

input:disabled { background-color: #eee; cursor: not-allowed; opacity: 0.7; } Top input is enabled - Bottom input is disabled

Different input types with disabled attribute


6. Disabled Textarea

Textarea can also be disabled Disabled textarea cannot be typed into

textarea:disabled { background-color: #eee; cursor: not-allowed; }

7. Disabled Div using pointer-events

Div and other non-form elements cannot use the disabled attribute in HTML. We use pointer-events: none in CSS instead

.div-disabled { pointer-events: none; opacity: 0.6; cursor: not-allowed; } Left div is clickable - Right div is disabled

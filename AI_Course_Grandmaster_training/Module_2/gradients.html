CSS Gradients

1. Linear Gradients

Colours change in a straight line direction

Left to Right

linear-gradient(to right, red, blue)

Top to Bottom

linear-gradient(to bottom, yellow, orange)

Diagonal

linear-gradient(to bottom right, purple, pink)

45 Degree Angle

linear-gradient(45deg, green, lightgreen)

Three Colours

linear-gradient(to right, red, yellow, blue)

Colour Stops

linear-gradient(to right, red 20%, white 50%, blue 80%)

2. Radial Gradients

Colours spread outward from the center

Circle

radial-gradient(circle, yellow, orange)

Ellipse

radial-gradient(ellipse, lightblue, darkblue)

Three Colours

radial-gradient(circle, white, lightblue, blue)

Dot Pattern

radial-gradient dot pattern trick

3. Conic Gradients

Colours go around a center point like a wheel

Colour Wheel

conic-gradient(red, yellow, green, blue, red)

Pie Chart

conic-gradient with percentage stops

With Starting Angle

conic-gradient(from 45deg, ...)

4. Repeating Gradients

Same gradient repeated as a pattern

Repeating Linear

repeating-linear-gradient diagonal stripes

Repeating Radial

repeating-radial-gradient circle rings

5. Gradient with Transparency

Using rgba() to add transparency to gradients

Transparent Gradient

rgba(0, 0, 255, 1) to rgba(0, 0, 255, 0)

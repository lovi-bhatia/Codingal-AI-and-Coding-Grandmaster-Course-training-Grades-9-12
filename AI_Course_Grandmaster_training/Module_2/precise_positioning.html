CSS Precise Positioning

1. position: static (Default)

Default value for all elements Elements follow normal document flow top right bottom left have NO effect

position: static; (default - no change) Static elements stack normally in document flow top left right bottom properties do nothing
position: static
top: 50px has no effect

2. position: relative

Element moves RELATIVE to its own normal position Original space is STILL reserved in document flow Other elements are NOT affected by the move

position: relative; top: 30px; left: 40px; Dashed box shows original position Blue box moved 30px down and 40px right from there
Original position here
top: 30px
left: 40px
position: relative; top: -15px; left: 20px; Negative top moves element UPWARD from its normal position
Original position here
top: -15px
left: 20px
Multiple elements - each moved relatively
left: 10px
top: 20px left: 30px
top: -10px

3. position: absolute

Element placed at EXACT position inside parent Parent must have position: relative Absolute element is REMOVED from normal flow

Parent: position: relative; Children: position: absolute; with top right bottom left Each coloured box is placed at an exact corner or center of the orange parent container
top: 10px left: 10px
top: 10px right: 10px
bottom: 10px left: 10px
bottom: 10px right: 10px
top: 50% left: 50% transform: translate (-50%, -50%)

5. position: fixed

Element is fixed to the BROWSER WINDOW Does NOT move when page is scrolled Always visible in same position

.navbar { position: fixed; top: 0; left: 0; width: 100%; } .chat-btn { position: fixed; bottom: 25px; right: 25px; } The BLUE NAVIGATION BAR at the very top of this page is using position: fixed - it stays there always. The GREEN CHAT button and BLUE UP button at bottom right are also using position: fixed. Scroll up and down to confirm they do not move.
Fixed elements on this page:

1. Blue navigation bar at TOP = position: fixed; top: 0; left: 0;

2. Green Chat button at BOTTOM RIGHT = position: fixed; bottom: 25px; right: 25px;

3. Blue Up arrow at BOTTOM RIGHT = position: fixed; bottom: 90px; right: 25px;

All three stay in same place no matter how much you scroll. This is the most common real world use of position: fixed.

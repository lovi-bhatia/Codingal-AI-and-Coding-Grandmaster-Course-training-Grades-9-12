4. opacity vs rgba() - Key Difference

opacity = everything fades including text rgba() = only background fades text stays visible

Left: opacity: 0.4 (text also fades) Right: rgba(30, 144, 255, 0.4) (text stays clear) Notice how text in the left box is also faded Text in the right box stays fully visible

Using opacity: 0.4

This text is ALSO faded because opacity affects everything including text. Hard to read!

Using rgba(blue, 0.4)

This text is FULLY VISIBLE because rgba only makes background transparent. Easy to read!

5. rgba() - Transparent Background Only

rgba makes ONLY the background transparent Text inside stays fully visible at all times

rgba(30, 144, 255, alpha) - only background transparency changes Text is always clearly readable regardless of alpha value

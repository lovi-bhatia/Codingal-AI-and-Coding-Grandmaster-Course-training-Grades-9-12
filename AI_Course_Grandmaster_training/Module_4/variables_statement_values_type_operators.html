JavaScript: Variables, Statements, Values, Types, Operators

1. Variables

Code: 
// Three ways to declare
const name = "Alex";   // fixed
let age = 20;          // changes later
var old = true;        // legacy (avoid)

age = 21;              // let can be reassigned
// name = "Sam";       // ERROR: const cannot change

let a = 1, b = 2, c;   // multiple at once
c = a + b;

console.log(name, age, old, c);

2. Statements vs Expressions

Code: 
// Expression: produces a value
const result = 5 + 3;      // 8

// Statement: performs an action
if (result > 5) {
  console.log("Big number");
}

// Block statement { } groups statements
{
  let hidden = "inside block";
  console.log(hidden);
}
// console.log(hidden);  // ERROR: out of scope

// Statements end with ; 
let x = 1;
x = x + 1;

6. Assignment Operators

Code: 
let x = 10;

x += 5;   // x = x + 5  → 15
x -= 3;   // x = x - 3  → 12
x *= 2;   // x = x * 2  → 24
x /= 4;   // x = x / 4  → 6

let count = 0;
count++;  // 1
count--;  // 0

console.log(x, count);

7. Comparison — === vs ==

Code: 
let a = 10, b = "10";

console.log(a == b);    // true (loose — converts)
console.log(a === b);   // false (strict — type differs)

console.log(5 !== "5"); // true
console.log(3 > 1);     // true
console.log(3 <= 3);    // true

// Rule: always prefer === and !==
Output:

8. Logical Operators

Code: 
const age = 20;
const hasId = true;

console.log(age > 18 && hasId);   // true
console.log(age > 30 || hasId);   // true
console.log(!hasId);              // false

// Default value trick with ||
const userName = "" || "Guest";

// Nullish coalescing (null/undefined only)
const port = null ?? 3000;

console.log(userName, port);

9. Ternary Operator (short if/else)

Code: 
const marks = 72;

const grade =
  marks >= 90 ? "A" :
  marks >= 60 ? "B" : "C";

console.log("Grade:", grade);

const canVote = marks >= 18 ? "yes" : "no";
console.log(canVote);

10. Operator Precedence

Code: 
// Multiplication runs before addition
console.log(2 + 3 * 4);     // 14

// Use () to control order
console.log((2 + 3) * 4);   // 20

// Comparison before &&
console.log(5 > 3 && 2 < 4);  // true

11. Quick Reference

Concept Syntax Note
Fixed variable const x = 5; Cannot be reassigned
Changeable variable let y = 5; Can be reassigned
Legacy variable var z = 5; Avoid in new code
Declaration statement let x = 10; Creates a variable
Expression 5 + 3 Produces a value
Block statement { ... } Groups statements, own scope
String "hi" Text in quotes
Number 42 Int or float
Boolean true true / false
Null null Intentionally empty
Undefined let x; Declared, no value
Check type typeof x Returns type as string
Strict comparison a === b Value AND type — preferred
Loose comparison a == b Converts types first — avoid
Logical AND a && b Both true → true
Logical OR a || b Either true → true
Nullish coalescing a ?? b Uses b only if a is null/undefined
Ternary c ? x : y Short if/else
Power 2 ** 3 2 to the power 3 → 8
Remainder 10 % 3 Returns 1

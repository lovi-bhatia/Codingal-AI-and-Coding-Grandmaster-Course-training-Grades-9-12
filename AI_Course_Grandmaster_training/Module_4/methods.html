JavaScript Methods and Test Methods

1. What Is a Method?

Code: 
const text = "hello";

// A method is a function attached to a value
console.log(text.toUpperCase());

// The value on the left of the dot
// is called the receiver
console.log([1, 2, 3].includes(2));
console.log(Math.max(1, 5, 3));
console.log((42).toString());

4. Array Methods That Change the Array

Code:

arr.push(4);      // add to end
arr.pop();        // remove from end
arr.unshift(0);   // add to start
arr.shift();      // remove from start

console.log(arr);

const arr2 = [10, 20, 30];
arr2.splice(1, 1);
console.log(arr2);

const arr3 = [3, 1, 2];
arr3.sort();
console.log(arr3);
arr3.reverse();
console.log(arr3);

10. Regex .test() — The Classic Test Method

Code: 
// /pattern/.test(string) → true / false

console.log(/\d+/.test("hello"));
console.log(/^[a-z]+$/.test("hello"));
console.log(/^[a-z]+$/.test("hello123"));

11. Quick Reference

Category Method Returns
String s.toUpperCase() new string
String s.includes("x") true / false
String s.split(",") array
Number n.toFixed(2) string
Number parseInt("42px") number
Array (mutating) arr.push(x) new length
Array (mutating) arr.pop() removed item
Array (mutating) arr.splice(i, n) removed items
Array (new value) arr.map(fn) new array
Array (new value) arr.filter(fn) new array
Array (new value) arr.reduce(fn, 0) single value
Object Object.keys(obj) array of keys
Object Object.values(obj) array of values
Object obj.hasOwnProperty("k") true / false
Test typeof x type name as string
Test Array.isArray(x) true / false
Test Number.isInteger(x) true / false
Test Number.isNaN(x) true / false (no conversion)
Test isNaN(x) true / false (converts first)
Test arr.some(fn) true if any pass
Test arr.every(fn) true if all pass
Test regex.test(str) true / false

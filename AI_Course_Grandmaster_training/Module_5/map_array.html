Mapping an Array (.map())

1. Basic Number Transformation

Doubling numbers without changing the original array.

Code: 
const numbers = [1, 2, 3, 4, 5];

// Map creates a new array with doubled values
const doubled = numbers.map(num => num * 2);

console.log("Original Numbers:", numbers); // Unchanged!
console.log("Doubled Array   :", doubled); // [2, 4, 6, 8, 10]

2. Extracting Properties from an Array of Objects

Mapping complex objects into a simple array of specific property values.

Code: 
const users = [
  { id: 1, name: "Alex", role: "Admin" },
  { id: 2, name: "Sam", role: "User" },
  { id: 3, name: "Maya", role: "User" }
];

// Extract only the names into a simple string array
const userNames = users.map(user => user.name);

console.log("User Names:", userNames);

3. Using Index in .map() Callback

Accessing the current element's index position during mapping.

Code: 
const fruits = ["Apple", "Banana", "Cherry"];

// Using second parameter (index)
const formattedList = fruits.map((fruit, index) => {
  return `${index + 1}. ${fruit}`;
});

console.log("Formatted List:", formattedList);

4. Real-World Use: Mapping Data to HTML Templates

Converting raw JS objects into HTML list items dynamically.

Code: 
const products = [
  { name: "Laptop", price: 999 },
  { name: "Phone", price: 699 }
];

// Map objects to HTML list item strings
const htmlItems = products.map(p => 
  `<li class="list-group-item">${p.name} - $${p.price}</li>`
).join(""); // Join array into single HTML string

console.log("HTML Output String:\n" + htmlItems);

    5. Quick Reference

    Feature Syntax / Pattern Behavior
    Basic Mapping arr.map(x => x * 2) Transforms each item, returns new array
    Property Extraction users.map(u => u.name) Extracts a specific property from objects
    Index Parameter arr.map((item, idx) => ...) Provides access to item index position
    HTML Generation arr.map(x => `<li>${x}</li>`).join("") Creates HTML templates for DOM insertion
    Mutates Original? No Original array remains untouched
    Returned Length Same length as input Always returns 1 output item for 1 input item

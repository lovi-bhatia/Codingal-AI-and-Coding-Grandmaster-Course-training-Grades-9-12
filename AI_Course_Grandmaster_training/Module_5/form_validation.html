JavaScript Validation Logic: 
form.addEventListener("submit", (e) => {
  e.preventDefault(); // Stop page reload
  let isValid = true;

  // 1. Username Check (Min 3 chars)
  if (usernameVal.length < 3) {
    showError(usernameInput, "Min 3 characters required");
    isValid = false;
  } else {
    showSuccess(usernameInput);
  }

  // 2. Email Regex Check
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(emailVal)) {
    showError(emailInput, "Invalid email format");
    isValid = false;
  } else {
    showSuccess(emailInput);
  }

  // 3. Password Match Check
  if (passwordVal !== confirmVal) {
    showError(confirmInput, "Passwords do not match");
    isValid = false;
  }
});

2. Quick Reference

Validation Rule JavaScript Code Pattern Description
Prevent Reload e.preventDefault() Stops form from performing default browser HTTP submission
Trim Input input.value.trim() Removes accidental whitespace from start/end of string
Non-Empty Check value === "" or !value.length Ensures required fields are populated
Email Regex /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email) Verifies email string contains @ and domain dot
Length Check password.length >= 8 Validates minimum or maximum character limits
Field Match pass1 === pass2 Ensures confirmation inputs match main input value
Bootstrap Valid UI elem.classList.add("is-valid") Applies green border and success styling
Bootstrap Invalid UI elem.classList.add("is-invalid") Applies red border and failure styling

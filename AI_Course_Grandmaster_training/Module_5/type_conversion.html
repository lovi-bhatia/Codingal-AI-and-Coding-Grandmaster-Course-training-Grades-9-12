JavaScript Type Conversion

1. Explicit Conversion to Number

Using Number(), parseInt(), and parseFloat().

Code: 
const strInt = "42";
const strFloat = "42.85";
const invalidStr = "100px";

console.log(Number(strInt));         // 42 (Number)
console.log(parseInt(strFloat));     // 42 (Truncates decimal)
console.log(parseFloat(strFloat));   // 42.85 (Preserves decimal)
console.log(parseInt(invalidStr));   // 100 (Extracts initial numbers)
console.log(Number(invalidStr));     // NaN (Fails completely)

2. Explicit Conversion to String & Boolean

Using String() and Boolean() explicit constructors.

Code: 
// String Conversion
console.log(String(100));            // "100"
console.log(String(true));           // "true"
console.log(String(null));           // "null"

// Boolean Conversion
console.log(Boolean(1));             // true
console.log(Boolean(0));             // false
console.log(Boolean("Hello"));       // true
console.log(Boolean(""));            // false

3. Implicit Coercion (Plus + vs Math Operators)

The + operator converts to String if a string is present, while -, *, / convert to Number.

Code: 
// Plus (+) prefers String concatenation
console.log("5" + 2);        // "52" (String)
console.log(1 + 2 + "3");    // "33" (String)

// Math operators (-, *, /) coerce to Number
console.log("5" - 2);        // 3 (Number)
console.log("10" * "2");     // 20 (Number)
console.log("10" / "2");     // 5 (Number)

// Unary plus (+) shorthand to convert to number
console.log(+"42");          // 42 (Number)

4. Implicit Coercion in Equality (== vs ===)

Loose equality == performs implicit coercion, while strict equality === compares value and type.

Code: 
console.log("5" == 5);       // true (Coerces string "5" to number 5)
console.log("5" === 5);      // false (Strict type check)

console.log(1 == true);      // true (Coerces true to number 1)
console.log(1 === true);     // false

console.log(null == undefined);  // true
console.log(null === undefined); // false

Sorting and Reversing Numbers

1. The Default Sort Bug vs Compare Function

Demonstrating why .sort() fails on numbers without a compare function.

Code: 
const scores = [100, 25, 5, 1, 80];

// BROKEN: Default sort converts to strings
const defaultSorted = [...scores].sort();

// CORRECT: Ascending numeric sort
const ascending = [...scores].sort((a, b) => a - b);

console.log("Original Array :", scores);
console.log("Default .sort():", defaultSorted); // [1, 100, 25, 5, 80] - WRONG
console.log("Numeric (a - b):", ascending);     // [1, 5, 25, 80, 100] - CORRECT

2. Ascending vs Descending Sort

Using (a - b) for ascending and (b - a) for descending order.

Code: 
const prices = [45, 12, 89, 3, 27];

// Ascending (Smallest to Largest)
const lowToHigh = [...prices].sort((a, b) => a - b);

// Descending (Largest to Smallest)
const highToLow = [...prices].sort((a, b) => b - a);

console.log("Low to High :", lowToHigh);
console.log("High to Low :", highToLow);

3. Reversing Numeric Arrays

Reversing flips the array elements regardless of numeric value.

Code: 
const numbers = [10, 20, 30, 40, 50];

// Reversing in-place
const reversed = [...numbers].reverse();

console.log("Original Array:", numbers);
console.log("Reversed Array:", reversed);

4. Reversing Digits of a Number

Converting a number to a string, splitting, reversing, and parsing back to a number.

Code: 
function reverseDigits(num) {
  // Handles negative numbers using Math.sign()
  const reversed = parseFloat(
    Math.abs(num).toString().split("").reverse().join("")
  );
  return reversed * Math.sign(num);
}

console.log("12345 ->", reverseDigits(12345));
console.log("-9876 ->", reverseDigits(-9876));

5. Real-World Use: Sorting Array of Objects by Price/Age

Sorting objects by a numeric property using compare functions.

Code: 
const products = [
  { name: "Laptop", price: 1200 },
  { name: "Mouse", price: 25 },
  { name: "Keyboard", price: 75 }
];

// Sort products by price ascending
const cheapestFirst = [...products].sort((a, b) => a.price - b.price);

console.log("Sorted by Price (Low to High):");
cheapestFirst.forEach(p => console.log(`${p.name}: $${p.price}`));

6. Quick Reference

Task Formula / Code Pattern Description
Ascending Sort nums.sort((a, b) => a - b) Sorts numbers from smallest to largest
Descending Sort nums.sort((a, b) => b - a) Sorts numbers from largest to smallest
Non-mutating Sort [...nums].sort((a, b) => a - b) Creates a sorted copy without changing original array
Reverse Array nums.reverse() Flips array order in place
Reverse Digits parseFloat(num.toString().split("").reverse().join("")) Reverses digits of a single number
Sort Object Array arr.sort((a, b) => a.prop - b.prop) Sorts objects based on a numeric property value

Evaluating Variables in JavaScript

1. Truthy & Falsy Evaluation

How variables evaluate in boolean contexts (like if conditions or Boolean() calls).

Code: 
const emptyText = "";
const zeroVal = 0;
const emptyArray = [];
const userObj = { name: "Alex" };

// Evaluating truthiness
console.log('"" evaluates to:', Boolean(emptyText));    // false
console.log('0 evaluates to:', Boolean(zeroVal));       // false
console.log('[] evaluates to:', Boolean(emptyArray));   // true (objects/arrays are truthy)
console.log('{} evaluates to:', Boolean(userObj));      // true

2. Short-Circuit Logical Evaluation (||, &&, ??)

Using logical operators to evaluate fallbacks and conditional execution.

Code: 
let inputName = "";
let userScore = 0;

// OR (||) -> Returns first truthy value (0 is falsy, so it returns "Guest")
const name1 = inputName || "Guest";

// NULLISH (??) -> Returns right side ONLY if left is null/undefined (0 is preserved!)
const score1 = userScore ?? 100;

// AND (&&) -> Evaluates right side ONLY if left side is truthy
const isLoggedIn = true;
const welcomeMsg = isLoggedIn && "Welcome back!";

console.log("Name fallback (||):", name1);
console.log("Score fallback (??):", score1);
console.log("Conditional (&&) :", welcomeMsg);

3. Dynamic Property Evaluation (Bracket Notation)

Evaluating a variable to determine which object property to access.

Code: 
const user = {
  firstName: "Alex",
  role: "Admin",
  age: 25
};

const keyToFetch = "role";

// Dot notation looks for property named "keyToFetch" (undefined)
console.log("Dot notation   :", user.keyToFetch);

// Bracket notation EVALUATES variable keyToFetch to "role"
console.log("Bracket notation:", user[keyToFetch]);

4. Template Literal Expression Evaluation (${})

JavaScript evaluates variables and math expressions inside backtick strings.

Code: 
const item = "Keyboard";
const price = 49.99;
const quantity = 2;

// Variables and mathematical expressions evaluate inside ${}
const summary = `Order: ${quantity}x ${item} | Total: $${(price * quantity).toFixed(2)}`;

console.log(summary);

5. Safe Dynamic String Evaluation (Avoiding eval())

Evaluating math expressions stored as strings safely using Function() instead of eval().

Code: 
const mathExpression = "15 * 4 + 10";

// Safe evaluation method using Function constructor
function evaluateMath(expr) {
  // Returns a function that evaluates the math expression
  return new Function(`return ${expr}`)();
}

const result = evaluateMath(mathExpression);
console.log(`Evaluating "${mathExpression}" ->`, result);

6. Quick Reference

Evaluation Pattern Syntax Example Evaluation Behavior
Truthy Check if (val) { ... } Evaluates val to boolean (falsy = false, 0, "", null, undefined, NaN)
Default Fallback val || "default" Returns "default" if val is any falsy value
Nullish Fallback val ?? "default" Returns "default" ONLY if val is null or undefined
Conditional Guard val && run() Runs run() ONLY if val evaluates to truthy
Dynamic Lookup obj[varName] Evaluates varName variable to get key name string
Template Interpolation `${x + y}` Evaluates expression x + y and converts result to string
Safe String Math Function("return " + str)() Evaluates mathematical expression string safely without eval()

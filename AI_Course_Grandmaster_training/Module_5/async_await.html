JavaScript Async / Await

1. Basic async / await Syntax

Writing asynchronous code that reads like synchronous code.

Code: 
// Mock async promise helper
function mockFetchUser() {
  return new Promise(resolve => {
    setTimeout(() => resolve({ id: 101, name: "Alex" }), 1000);
  });
}

// Async function using await
async function getUserData() {
  console.log("1. Starting fetch...");
  
  // Pauses execution until promise resolves
  const user = await mockFetchUser();
  
  console.log("2. User received:", user.name);
  return user;
}

getUserData();

2. Error Handling using try...catch

Handling rejected promises cleanly using standard try/catch blocks.

Code: 
function mockFailingApi() {
  return new Promise((_, reject) => {
    setTimeout(() => reject(new Error("Network Timeout")), 1000);
  });
}

async function loadDataSafely() {
  try {
    const result = await mockFailingApi();
    console.log(result);
  } catch (error) {
    console.log("Caught Error:", error.message);
  } finally {
    console.log("Loading state reset.");
  }
}

loadDataSafely();

3. Parallel Execution with Promise.all()

Awaiting multiple independent asynchronous requests simultaneously.

Code: 
const fetchPosts = () => new Promise(r => setTimeout(() => r("Posts"), 800));
const fetchComments = () => new Promise(r => setTimeout(() => r("Comments"), 800));

async function loadDashboardParallel() {
  // Runs both fetch operations simultaneously in parallel
  const [posts, comments] = await Promise.all([
    fetchPosts(),
    fetchComments()
  ]);

  console.log("Parallel Loaded:", posts, "&", comments);
}

4. Real-World Use: Fetching API Data

Using async/await with the browser's built-in fetch() API.

Code: 
async function fetchExternalTodo() {
  try {
    // 1. Fetch response stream
    const res = await fetch("https://jsonplaceholder.typicode.com/todos/1");
    
    // 2. Parse JSON body
    const todo = await res.json();
    
    console.log("Todo Title:", todo.title);
  } catch (err) {
    console.log("Fetch Error:", err.message);
  }
}

5. Quick Reference

Keyword / Pattern Syntax Example Behavior
async function async function f() {} Forces function to return a Promise automatically
await keyword const res = await promise Pauses execution until Promise settles; returns result
Error Handling try { await ... } catch (e) {} Catches rejected promises using standard try/catch blocks
Parallel Execution await Promise.all([p1, p2]) Executes multiple async tasks simultaneously instead of sequentially
Placement Rule Inside async functions only await cannot be used in standard synchronous functions

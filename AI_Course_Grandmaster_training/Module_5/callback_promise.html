JavaScript Callbacks & Promises

1. Asynchronous Callbacks

Passing a function as an argument to execute after a task completes.

Code: 
function fetchUserCallback(userId, callback) {
  setTimeout(() => {
    const user = { id: userId, name: "Alex" };
    callback(user); // Execute callback with result
  }, 1000);
}

console.log("Fetching user...");
fetchUserCallback(101, (data) => {
  console.log("Callback Received:", data.name);
});

2. Creating & Consuming Promises (.then, .catch)

Replacing callbacks with clean Promise objects handling success and failure states.

Code: 
function checkInventory(item) {
  return new Promise((resolve, reject) => {
    const inStock = true;
    
    if (inStock) {
      resolve(`${item} is in stock!`); // Fulfilled
    } else {
      reject(`${item} is out of stock.`); // Rejected
    }
  });
}

checkInventory("Laptop")
  .then(message => console.log("Success:", message))
  .catch(error => console.log("Error:", error))
  .finally(() => console.log("Inventory check complete"));

3. Sequential Execution via Promise Chaining

Executing asynchronous tasks sequentially without nesting callbacks.

Code: 
function step1() {
  return Promise.resolve("Step 1 Complete");
}
function step2(msg) {
  return Promise.resolve(`${msg} -> Step 2 Complete`);
}

step1()
  .then(res1 => step2(res1))
  .then(res2 => console.log("Chain Result:", res2));

4. Parallel Execution with Promise.all()

Running multiple promises in parallel and waiting for all to complete.

Code: 
const p1 = Promise.resolve("User Data");
const p2 = Promise.resolve("Posts Data");
const p3 = Promise.resolve("Comments Data");

Promise.all([p1, p2, p3])
  .then(results => {
    console.log("All Promises Resolved:", results);
  });

5. Quick Reference

Concept Syntax / Pattern Description
Callback fn(arg, (data) => {}) Function passed as argument to execute after async task completes
Callback Hell Deeply nested callbacks Unreadable pyramid code structure resulting from nested async tasks
New Promise new Promise((res, rej) => {}) Creates async wrapper object with resolve and reject handles
.then() promise.then(data => {}) Executes when promise is successfully fulfilled (resolved)
.catch() promise.catch(err => {}) Executes when promise fails (rejected)
.finally() promise.finally(() => {}) Executes ALWAYS after promise settles regardless of success/fail
Promise.all() Promise.all([p1, p2]) Waits for all promises in array to resolve; fails if any fails

JavaScript Conditional Statements

1. if, else if, and else

Code: 
const temperature = 28;
let result;

if (temperature > 30) {
  result = "Hot day";
} else if (temperature >= 20) {
  result = "Warm day";
} else if (temperature >= 10) {
  result = "Cool day";
} else {
  result = "Cold day";
}

console.log(result);

2. Ternary Operator (condition ? true : false)

Shorthand for simple if...else expressions.

Code: 
const userAge = 20;

// Ternary assignment
const access = userAge >= 18 ? "Granted" : "Denied";

// Nested ternary (use sparingly for readability)
const category = userAge < 13 ? "Child" : userAge < 20 ? "Teen" : "Adult";

console.log("Access:", access);
console.log("Category:", category);

3. Truthy and Falsy Conditions

Non-boolean values implicitly convert to boolean inside conditional statements.

Code: 
const username = ""; // Empty string = Falsy
const cartItems = [1, 2]; // Non-empty array = Truthy

if (username) {
  console.log("Welcome, " + username);
} else {
  console.log("User is a Guest (Falsy string)");
}

if (cartItems.length) {
  console.log(`Cart has ${cartItems.length} items (Truthy number)`);
}

4. Logical Operators (&&, ||, !) & Short-Circuiting

Code: 
const isLoggedIn = true;
const hasSubscription = false;

// AND (&&) requires both true
if (isLoggedIn && hasSubscription) {
  console.log("Access Premium Content");
} else {
  console.log("Subscription required");
}

// Short-circuit OR (||) fallback
const displayName = username || "Default Guest";

console.log("Display Name:", displayName);

5. Quick Reference

Statement / Operator Syntax Example Behavior
if if (cond) { ... } Executes block if condition is truthy
if...else if (cond) {} else {} Provides alternative execution path for falsy conditions
else if else if (cond2) {} Chains secondary conditions sequentially
Ternary a ? b : c Inline evaluation returning b if truthy, c if falsy
Falsy Values false, 0, "", null, undefined, NaN The 6 values that evaluate to false in conditionals
AND (&&) cond1 && cond2 Evaluates to true only if BOTH operands are truthy
OR (||) cond1 || cond2 Evaluates to true if AT LEAST ONE operand is truthy
NOT (!) !condition Inverts boolean status (!true becomes false)

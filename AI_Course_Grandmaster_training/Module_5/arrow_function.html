JavaScript Arrow Functions

1. Arrow Function Syntax Variations

Demonstrating implicit returns, single parameters, and returning object literals.

Code: 
// 1. Multiple params with implicit return
const add = (a, b) => a + b;

// 2. Single param (no parentheses needed)
const double = n => n * 2;

// 3. Zero params (parentheses required)
const sayHi = () => "Hello World!";

// 4. Implicitly returning an Object (wrapped in parentheses)
const createPoint = (x, y) => ({ x: x, y: y });

console.log(add(5, 10));
console.log(double(7));
console.log(sayHi());
console.log(createPoint(10, 20));

2. Lexical this in Callbacks

Arrow functions inherit this from the outer scope, fixing callback context loss.

Code: 
const timer = {
  seconds: 0,
  start() {
    // Arrow function preserves 'this' from timer object
    setInterval(() => {
      this.seconds++;
      console.log("Timer seconds:", this.seconds);
    }, 1000);
  }
};

// 'this' inside setInterval remains pointing to 'timer'

3. When NOT to Use Arrow Functions

Avoid arrow functions as Object Methods or Constructor Functions.

Code: 
const user = {
  name: "Alex",
  
  // BAD: Arrow function method (this refers to window/undefined)
  badGreet: () => `Hi, I am ${this.name}`,
  
  // GOOD: ES6 Method shorthand
  goodGreet() {
    return `Hi, I am ${this.name}`;
  }
};

console.log("Bad Greet :", user.badGreet());  // undefined!
console.log("Good Greet:", user.goodGreet()); // "Hi, I am Alex"

4. Arrow Functions with Array Iterators

Concise inline arrow functions with .map(), .filter(), and .reduce().

Code: 
const numbers = [1, 2, 3, 4, 5];

// Concise inline processing
const evenDoubled = numbers
  .filter(n => n % 2 === 0)
  .map(n => n * 2);

console.log("Even Doubled:", evenDoubled);

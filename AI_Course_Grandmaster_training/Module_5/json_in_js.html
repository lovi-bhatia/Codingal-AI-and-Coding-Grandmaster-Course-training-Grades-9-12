JavaScript JSON (JavaScript Object Notation)

1. Converting JS Object to JSON String (JSON.stringify)

Packaging a JavaScript object into a JSON formatted string.

Code: 
const userObj = {
  id: 101,
  name: "Alex",
  isAdmin: true,
  skills: ["HTML", "JS"]
};

// Convert JS Object to JSON String
const jsonString = JSON.stringify(userObj);

console.log("Type of output:", typeof jsonString);
console.log("JSON String   :", jsonString);

2. Parsing JSON String back to JS Object (JSON.parse)

Unpackaging a JSON formatted string into a usable JavaScript Object.

Code: 
// Valid JSON string (Keys and Strings must use double quotes!)
const rawJson = '{"id":202,"title":"Headphones","price":99.99}';

// Convert JSON String to JS Object
const productObj = JSON.parse(rawJson);

console.log("Type of output :", typeof productObj);
console.log("Product Title  :", productObj.title);
console.log("Product Price  :", productObj.price);

3. Formatting JSON Output (Pretty Printing)

Passing indentation arguments to JSON.stringify(obj, replacer, space).

Code: 
const student = { name: "Sam", age: 22, grade: "A" };

// Format JSON string with 2-space indentation
const prettyJson = JSON.stringify(student, null, 2);

console.log(prettyJson);

4. Real-World Use: Storing Objects in localStorage

localStorage can only store strings. Use JSON to store and retrieve complex objects.

Code: 
const settings = { theme: "dark", fontSize: 16 };

// 1. Save object to localStorage as JSON string
localStorage.setItem("userSettings", JSON.stringify(settings));

// 2. Retrieve JSON string and parse back to object
const savedString = localStorage.getItem("userSettings");
const loadedSettings = JSON.parse(savedString);

console.log("Loaded Theme:", loadedSettings.theme);

5. Quick Reference

Method Input Type Output Type Primary Purpose
JSON.stringify(obj) JS Object / Array JSON String Converts object to string for sending/saving data
JSON.parse(string) JSON String JS Object / Array Parses string received from server/storage into JS object
JSON.stringify(obj, null, 2) JS Object Formatted String Pretty-prints JSON string with 2-space indentation
Syntax Rule 1 Double Quotes Mandatory All keys and string values MUST use double quotes "key"
Syntax Rule 2 Trailing Commas Forbidden No comma allowed after the last property item

Sorting and Reversing Strings

1. Reversing a String (split -> reverse -> join)

Converting a string to a character array, flipping it, and joining it back.

Code: 
function reverseString(str) {
  return str.split("").reverse().join("");
}

const original = "Bootstrap";
const reversed = reverseString(original);

console.log("Original:", original);
console.log("Reversed:", reversed);

2. Sorting String Characters Alphabetically

Arranging characters of a string in alphabetical order.

Code: 
const word = "webdeveloper";

// Standard ASCII sort
const sorted = word.split("").sort().join("");

3. Case-Insensitive String Sorting (localeCompare)

Standard .sort() puts uppercase before lowercase. Use localeCompare for true alphabetical order.

Code: 
const mixedStr = "bA cD";

// Default ASCII sort (Uppercase first)
const asciiSort = mixedStr.split("").sort().join("");

// Case-insensitive sort using localeCompare
const caseInsensitiveSort = mixedStr.split("").sort((a, b) => 
  a.localeCompare(b, undefined, { sensitivity: 'base' })
).join("");

console.log("Default ASCII Sort:", asciiSort);
console.log("Case-Insensitive :", caseInsensitiveSort);

4. Reversing Words in a Sentence

Splitting by spaces (split(" ")) to reverse word order while keeping word letters intact.

Code: 
const sentence = "JavaScript is awesome";

// Reverse word order
const reversedSentence = sentence.split(" ").reverse().join(" ");

console.log("Original Sentence:", sentence);

5. Real-World Application: Palindrome Checker

Checking if a string reads the same backwards and forwards.

Code: 
function isPalindrome(str) {
  // Clean string: lowercase and remove non-alphanumeric chars
  const cleanStr = str.toLowerCase().replace(/[^a-z0-9]/g, "");
  const reversedStr = cleanStr.split("").reverse().join("");
  return cleanStr === reversedStr;
}

console.log("racecar  ->", isPalindrome("racecar"));
console.log("hello    ->", isPalindrome("hello"));
console.log("A man, a plan, a canal: Panama ->", isPalindrome("A man, a plan, a canal: Panama"));

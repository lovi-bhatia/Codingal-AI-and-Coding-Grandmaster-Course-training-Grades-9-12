Generate Random Numbers Using a While Loop

1. Roll a Die Until a 6 Appears

Repeats random number generation until a specific target number is rolled.

Code: 
let roll = 0;
let attempts = 0;

// Keep rolling while roll is NOT 6
while (roll !== 6) {
  // Generate random integer from 1 to 6
  roll = Math.floor(Math.random() * 6) + 1;
  attempts++;
  console.log(`Attempt ${attempts}: Rolled a ${roll}`);
}

console.log(`Success! Hit 6 in ${attempts} attempts.`);

2. Generate N Unique Random Numbers (Lottery Style)

Uses a while loop to fill an array with random numbers, ignoring duplicate values.

Code: 
const uniqueNumbers = [];
const countNeeded = 5;

// Loop until we have exactly 5 UNIQUE numbers
while (uniqueNumbers.length < countNeeded) {
  // Generate random number from 1 to 20
  const randomNum = Math.floor(Math.random() * 20) + 1;

  // Add to array ONLY if it doesn't already exist
  if (!uniqueNumbers.includes(randomNum)) {
    uniqueNumbers.push(randomNum);
  }
}

console.log("Unique Numbers:", uniqueNumbers);

3. Random Generation with Max Attempt Safety Guard

Prevents infinite loops by setting a maximum attempt limit.

Code: 
let currentNum = 0;
let totalRolls = 0;
const MAX_ATTEMPTS = 100; // Safety limit

// Loop stops if number > 95 OR if max attempts exceeded
while (currentNum <= 95 && totalRolls < MAX_ATTEMPTS) {
  currentNum = Math.floor(Math.random() * 100) + 1;
  totalRolls++;
}

console.log(`Stopped at ${currentNum} after ${totalRolls} rolls`);

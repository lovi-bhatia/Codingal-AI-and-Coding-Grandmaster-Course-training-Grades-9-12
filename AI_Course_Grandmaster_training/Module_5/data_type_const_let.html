JavaScript Data Types, let and const

1. Primitive Data Types

Code: 
const str = "Hello World";     // String
const num = 42;                // Number
const isVal = true;            // Boolean
let unassigned;                // Undefined
const emptyVal = null;        // Null
const bigIntNum = 9007199254740991n; // BigInt
const sym = Symbol("id");      // Symbol

console.log(typeof str);       // string
console.log(typeof num);       // number
console.log(typeof isVal);     // boolean
console.log(typeof unassigned); // undefined
console.log(typeof emptyVal);  // object (JS quirk)
console.log(typeof bigIntNum); // bigint
console.log(typeof sym);       // symbol

2. Reference Data Types (Objects & Arrays)

Code: 
const user = { name: "Alex", age: 20 }; // Object
const numbers = [10, 20, 30];            // Array
function greet() { return "Hi"; }        // Function

console.log(typeof user);     // object
console.log(typeof numbers);  // object
console.log(typeof greet);    // function

// Value vs Reference Demonstration
let x = 10;
let y = x; // Copy of value
y = 20;

const obj1 = { val: 10 };
const obj2 = obj1; // Copy of reference
obj2.val = 20;

console.log("Primitive x:", x);   // 10 (unchanged)
console.log("Object obj1:", obj1.val); // 20 (mutated)

3. The let Keyword (Reassignable & Block Scoped)

Code: 
let score = 50;
score = 75; // Valid reassignment

if (true) {
  let blockScore = 100;
  console.log("Inside block:", blockScore);
}

console.log("Reassigned score:", score);

4. The const Keyword (Binding Protection vs Mutation)

Code: 
const TAX_RATE = 0.18;
// TAX_RATE = 0.20; // TypeError: Assignment to constant variable

// const protects binding, NOT object content (mutation allowed)
const person = { name: "Sam" };
person.name = "Maya"; // Valid mutation
person.age = 25;     // Valid addition

const colors = ["Red", "Green"];
colors.push("Blue"); // Valid mutation

console.log("Tax Rate:", TAX_RATE);
console.log("Mutated Person:", person);
console.log("Mutated Colors:", colors);

Code: 
// var leaks out of block scope

6. Quick Reference

Concept Type / Keyword Key Characteristics
Primitives String, Number, Boolean, Undefined, Null, BigInt, Symbol Immutable single values; stored by value in stack memory
Reference Types Object, Array, Function Mutable collections; stored by reference in heap memory
typeof Quirk typeof null Returns "object" due to historic JS implementation
let Variable Keyword Block scoped, reassignable, cannot be redeclared in same scope
const Variable Keyword Block scoped, non-reassignable binding, requires initial value
Mutation const obj = {} Properties/elements of const objects/arrays CAN be changed
Scope Block { } vs Function let/const observe block scope; var observes function scope

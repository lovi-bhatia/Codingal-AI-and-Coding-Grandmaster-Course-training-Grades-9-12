JavaScript The this Keyword

1. Object Methods (Implicit Binding)

Inside an object method, this points to the object to the left of the dot.

Code: 
const user = {
  name: "Alex",
  age: 25,
  getDetails() {
    return `${this.name} is ${this.age} years old`;
  }
};

// user is to the left of the dot -> 'this' === user
console.log(user.getDetails());

2. Arrow Functions vs Regular Functions

Arrow functions do not have their own this; they inherit it from the surrounding scope.

Code: 
const group = {
  title: "Dev Team",
  members: ["Sam", "Maya"],
  
  // Regular function method
  showMembers() {
    // Arrow function inherits 'this' from showMembers()
    this.members.forEach(member => {
      console.log(`${member} is in ${this.title}`);
    });
  }
};

group.showMembers();

3. Explicit Binding (call, apply, bind)

Manually forcing a function's this to point to a specific object.

Code: 
function introduce(city, country) {
  return `I am ${this.name} from ${city}, ${country}`;
}

const person1 = { name: "Ravi" };
const person2 = { name: "Sarah" };

// .call() -> passes arguments individually
const res1 = introduce.call(person1, "Delhi", "India");

// .apply() -> passes arguments as an array
const res2 = introduce.apply(person2, ["London", "UK"]);

// .bind() -> returns a NEW function with 'this' locked
const boundFunc = introduce.bind(person1, "Mumbai", "India");
const res3 = boundFunc();

console.log(res1);
console.log(res2);
console.log(res3);

4. Constructor Functions & Classes (new Binding)

When invoked with new, this binds to the new instance being created.

Code: 
function Car(brand, model) {
  // 'this' refers to the new blank object being created
  this.brand = brand;
  this.model = model;
  
  this.getInfo = function() {
    return `${this.brand} ${this.model}`;
  };
}

const car1 = new Car("Toyota", "Corolla");
const car2 = new Car("Tesla", "Model 3");

console.log(car1.getInfo());
console.log(car2.getInfo());

5. DOM Event Listener Binding

In standard event listener callbacks, this refers to the target element.

Code: 
const btn = document.getElementById("demo-btn");

btn.addEventListener("click", function() {
  // 'this' refers to the button DOM element
  document.getElementById("out5").textContent = 
    `Clicked Button ID: ${this.id} | Tag: ${this.tagName}`;
});

Searching and Replacing Strings

1. String Search Methods

Using .includes(), .indexOf(), .startsWith(), and .endsWith().

Code: 
const text = "JavaScript is modern and flexible";

console.log(text.includes("modern"));    // true
console.log(text.indexOf("modern"));     // 14 (Index position)
console.log(text.indexOf("Python"));     // -1 (Not found)
console.log(text.startsWith("Java"));    // true
console.log(text.endsWith("flexible"));  // true

2. Replaces First Match vs Replaces All Matches

Comparing .replace() (first match) against .replaceAll() (all matches).

Code: 
const sentence = "The cat sat on the cat mat";

// .replace() only replaces the FIRST occurrence
const singleReplace = sentence.replace("cat", "dog");

// .replaceAll() replaces ALL occurrences
const allReplace = sentence.replaceAll("cat", "dog");

console.log("Original String  :", sentence);
console.log(".replace()      :", singleReplace);
console.log(".replaceAll()   :", allReplace);

3. Replacing with Regular Expressions (/pattern/gi)

Using regex flags: /g (global - replace all) and /i (case-insensitive).

Code: 
const mixedText = "JS is great. I love js and Js!";

// Case-insensitive replacement (/i) - First match only
const replaceI = mixedText.replace(/js/i, "JavaScript");

// Global & Case-insensitive replacement (/gi) - All matches
const replaceGI = mixedText.replace(/js/gi, "JavaScript");

console.log("Case-Insensitive (/i) :", replaceI);
console.log("Global & Case-Ins. (/gi):", replaceGI);

4. Dynamic Replacements Using Functions

Passing a callback function into .replace() to transform matched strings dynamically.

Code: 
const statement = "I have 2 apples and 5 oranges";

// Dynamically double any numbers found in string
const doubledText = statement.replace(/\d+/g, (match) => {
  return Number(match) * 2;
});

console.log("Original:", statement);
console.log("Doubled :", doubledText);

5. Quick Reference

Method / Pattern Syntax Behavior
Check Existence str.includes("target") Returns true if substring exists anywhere
Find Index str.indexOf("target") Returns start index position, or -1 if not found
Check Boundaries str.startsWith() / str.endsWith() Returns true if string starts/ends with search term
Replace First Match str.replace("a", "b") Replaces ONLY the first occurrence of "a" with "b"
Replace All Matches str.replaceAll("a", "b") Replaces ALL occurrences of "a" with "b"
Regex Global Replace str.replace(/a/g, "b") Replaces all occurrences using global regex flag
Regex Case-Insensitive str.replace(/a/gi, "b") Replaces all occurrences ignoring case differences

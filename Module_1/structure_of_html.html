How HTML is Structured

An HTML document is made of tags inside of other tags. Here are the basic parts:

1. The Setup

  • <!DOCTYPE html> - This goes at the very top. It tells the browser you are using modern HTML.
  • <html> - This holds the entire webpage. Everything else goes inside this tag.

2. The Head (Hidden Info)

The <head> tag holds information for the browser. You don't see this on the webpage itself.

  • <title> - This goes inside the head. It makes the text that shows up in your browser's top tab.

3. The Body (Visible Page)

The <body> tag holds everything you actually see on the screen.

  • <h1> to <h6> - Used for large headings.
  • <p> - Used for standard paragraphs.
  • <ul> and <li> - Used to make bulleted lists, exactly like the one you are reading right now!

The Basic Code Skeleton

Here is what the raw code for a basic webpage looks like:

<!DOCTYPE html>
<html>
    <head>
        <title>My Page Name</title>
    </head>
    <body>
        <h1>Welcome to my website</h1>
        <p>This is a paragraph of text.</p>
    </body>
</html>

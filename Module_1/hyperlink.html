How to Create Links in HTML

The text you want people to click goes inside the <a> tags. The website URL goes inside the href attribute.

1. A Basic Link to Another Website

This is the most common type of link.

Click here to go to Google

2. A Link That Opens in a New Tab

If you don't want the user to leave your page, you can make the link open in a new tab by adding target="_blank".

Open Wikipedia in a new tab

3. A Link to an Email Address

You can create a link that automatically opens the user's email program by typing mailto: before the email address.

Click here to send me an email

4. A Link Using an Image

You don't have to just use text! You can turn other things into links, like formatting tags or images.

Click this bold text to go to NASA!

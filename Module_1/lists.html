Creating Lists in HTML

All lists use the <li> tag for the actual list items, but they change depending on what tag you wrap around them.

1. Unordered Lists (Bullet Points)

Use the <ul> tag when the order of the items does not matter, like a grocery list.

  • Apples
  • Bananas
  • Bread

2. Ordered Lists (Numbered)

Use the <ol> tag when the items need to be in a specific order, like steps in a recipe.

  1. Preheat the oven
  2. Mix the ingredients
  3. Bake for 20 minutes

3. Nested Lists (Lists inside of lists)

You can create sub-bullets by putting a new list inside of an existing list item.

  • Drinks
    • Water
    • Coffee
  • Food
    • Pizza
    • Salad
